# Prompt Generator 🚀

A simple prompt generator built using **Python, LangChain, and Google Gemini API**.

## Features

* Image prompts
* Coding prompts
* Writing prompts
* Study prompts

## Tech Used

* Python
* LangChain
* Google Gemini API
* Git & GitHub

## How to Run

1. Create a virtual environment:

python -m venv venv


2. Activate it:

source venv/Scripts/activate


3. Install dependencies:

pip install -r requirements.txt


4. Add your Gemini API key to `.env`:

GOOGLE_API_KEY=your_api_key


5. Run:

python main.py
